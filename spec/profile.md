# Personal profile specification

- Selecting the Home profile affordance opens a native personal-profile screen.
- Back closes the profile screen and returns to the retained Home destination.
- Without an authenticated profile contract, the screen renders the signed-out card and Log in
  action.
- App settings, About StreamTV, Privacy policy, Terms and conditions and Feedback appear in grouped
  action sections matching the Android reference hierarchy.
- Until their shared contracts and destinations exist, Log in and profile actions provide explicit
  unavailable feedback rather than acting as dead controls.
