## 1. Full-screen Home category picker

Android now opens `ItemSelectionDialogFragment` from both the **More** category and the compact
category title. The old simple choice alert is gone.

- The picker is full-screen with Back, title and Continue chrome.
- The active category starts centred.
- `SliderLayoutManager` scales and fades rows by their distance from the vertical centre.
- `CustomLinearSnapHelper` settles the nearest row at centre.
- First tap on an off-centre row scrolls it to centre; tapping the centred row commits it.
- Continue commits the centred row. Back dismisses without changing category.
- The synthetic More item opens the picker and is never committed as a content category.

iOS checklist:

- [x] Present an equivalent full-screen SwiftUI category wheel from More and the compact title.
- [x] Restore/centre the selected category and reproduce centre-weighted scale/opacity.
- [x] Match the two-step off-centre tap, centred tap, Continue and cancel behavior.
- [x] Keep More as a launcher only.

## 2. Story reaction motion

Android story reactions now clone the selected emoji into an animation layer instead of only
scaling the source button.

- A selected emoji travels upward by five button heights and fades out over 800 ms.
- The initial story emits 30–60 random reactions at 100 ms intervals (roughly 3–6 seconds).
- Android reuses at most 50 transient `TextView`s and cancels/recycles all animation work on pause
  or view destruction.

iOS checklist:

- [x] Replace the current reaction toast-only behavior with a transient floating emoji layer.
- [x] Match the 800 ms upward/fade motion and approximate five-button travel distance.
- [x] Play the randomized initial burst only once for the initial story presentation.
- [x] Bound transient reaction state and cancel it when the story view disappears/backgrounds.

## 3. Mini-player controls and surface color

Android's minimized player no longer expands when a transport control is pressed. The parent card
gesture explicitly excludes the visible footer hit rectangle.

- Rewind, play/pause/replay and forward execute while the player remains minimized.
- Tapping an unoccupied portion of the card still expands it.
- Mini footer and transport backgrounds use the app background token (`#111111`).

iOS checklist:

- [x] Ensure every mini transport consumes its tap before the card expansion gesture.
- [x] Verify rewind, play, pause, replay and forward leave the presentation minimized.
- [x] Use `StreamTheme`'s app background for the footer and all transport hit surfaces.

## 4. Personal profile screen

non-exported native Activity.

- Top bar with Back and **Personal profile**.

- Spaced/outlined sections for App settings, About StreamTV, Privacy policy, Terms and conditions,

- Home Profile and Short toolbar Profile both open this screen.
- Authentication/settings/legal/feedback destinations are not in the shared contract yet, so rows

## 5. Short action rail and actions

Android's Short page now matches `on-tv-android`'s action rail rather than the previous custom
stack.

- A 48 dp circular provider avatar has the plus/check follow control overlaid at its bottom edge.
  Following is optimistic, applies provider-wide through `ShortViewModel`, shows the check state for
  one second and then hides the control.
- Like, Comment, Share and More are vertically stacked text-top `MaterialButton`s with 32 dp icons.
- Like uses activated outline/fill state and an optimistic compact count.
- Comment shows the compact count. It opens a full bottom sheet, displays locally submitted
  comments and accepts a non-blank comment; submission updates the shared count.
- Share displays the **Share** label (not share count) and opens Android's `ACTION_SEND` chooser with
  title and video URL.
- More opens a bottom sheet with Copy link, Not interested and Report. Copy writes the URL to the
  clipboard; Not interested advances to the next item when possible; Report shows confirmation and
  local completion feedback until the report API exists.
- Avatar/provider name opens a provider dialog listing the provider's loaded shorts and a follow
  action. Search finds the first loaded title/provider match. The toolbar profile icon opens the
  personal-profile screen.
- Tapping video uses the reference play feedback: pausing scales the centre icon into view for
  100 ms; resuming fades it out over 150 ms.

Shared contract changes available to iOS:

- `ShortItemUiModel.commentCount` exposes the raw count alongside `commentCountLabel`.
- `ShortViewModel.addComment(id, comment)` trims/rejects blank text, stores the local comment and
  increments the item's count/label.
- `ShortViewModel.commentsFor(id)` returns locally submitted comments.

- [x] Hide the follow affordance after following and use the shared provider-wide follow state.
- [x] Add the same pause/resume centre-indicator motion.
